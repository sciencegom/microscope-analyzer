# 현미경 이미지 길이·면적 분석기

대물마이크로미터 기준 사진으로 픽셀 축척을 보정한 뒤, 현미경 사진에서 **길이·원 지름·다각형 면적·시야 면적**을 측정하는 과학교육용 웹 애플리케이션입니다.

- 웹앱: <https://sciencegom.github.io/microscope-analyzer/>
- 제작: LJB · DGHS (Daejeon Goejeong High School)
- 실행 환경: 최신 Chrome 또는 Microsoft Edge 권장
- 처리 방식: 별도 서버 없이 사용자의 웹 브라우저 내부에서 이미지 처리
- 라이선스: MIT

## 주요 기능

- 처음 사용하는 학생을 위한 단계별 안내 모드
- 익숙한 사용자를 위한 전체 설정 보기
- 대물마이크로미터 기준 이미지로 `μm/px` 축척 보정
- 최대 3회 반복 보정과 평균값·표준편차 확인
- 접안렌즈, 대물렌즈, 시야수(FN)를 이용한 이론 시야 계산
- 시야 경계 3점으로 실측 시야 원 지정
- 선 길이와 원 지름 측정
- 꼭짓점을 지정하는 다각형 면적 측정
- 측정 영역의 둘레와 원형도 계산
- 시야 전체 면적, 이미지 유효 면적 및 포함 비율 계산
- 스케일바 삽입과 위치 조절
- 측정 표시와 분석값이 포함된 PNG 저장
- 측정값 CSV 저장
- 보정 프로필 저장 및 다시 불러오기
- 화면 확대·축소, 이동 및 실행 취소

## 측정 원리

기준 이미지에서 실제 길이를 알고 있는 눈금 구간을 지정하면 다음과 같이 축척을 계산합니다.

```text
축척(μm/px) = 기준 구간의 실제 길이(μm) ÷ 기준 구간의 픽셀 길이(px)

실제 길이(μm) = 측정 픽셀 길이(px) × 축척(μm/px)

실제 면적(μm²) = 측정 픽셀 면적(px²) × 축척²
```

여러 번 보정한 경우 선택된 보정값의 평균을 최종 축척으로 사용합니다.

## 기본 사용 방법

앱은 처음 열면 `학생용 안내` 모드로 시작합니다. 완료된 단계는 접히고 다음 단계가 자동으로 열립니다. 모든 입력값과 도구를 한 화면에서 사용하려면 상단의 `전체 설정`을 선택합니다.

### 1. 기준 이미지 준비

측정에 사용할 현미경과 같은 조건으로 대물마이크로미터를 촬영합니다.

- 같은 대물렌즈 배율
- 같은 카메라와 어댑터
- 같은 디지털 줌
- 같은 촬영 해상도와 크롭 조건

이 조건 중 하나라도 달라지면 픽셀 축척이 달라질 수 있으므로 다시 보정해야 합니다.

### 2. 기준 이미지 불러오기

`기준 이미지 선택`을 누르고 대물마이크로미터 사진을 불러옵니다. JPG, PNG 및 WEBP 형식을 사용할 수 있습니다.

### 3. 축척 보정

1. 보정할 눈금 구간의 실제 길이와 단위를 입력합니다.
2. `보정선 그리기`를 누릅니다.
3. 눈금 구간의 양 끝을 차례로 클릭합니다.
4. 필요하면 서로 다른 구간에서 최대 3회 반복합니다.
5. 사용할 측정값을 확인하고 `평균 보정값 적용`을 누릅니다.

가능하면 너무 짧은 한 칸보다 여러 눈금에 걸친 긴 구간을 사용하는 것이 클릭 오차를 줄이는 데 유리합니다.

### 4. 광학 정보와 시야 확인

접안렌즈 배율, 시야수(FN), 대물렌즈 배율을 입력합니다.

```text
이론 시야 지름 = 시야수(FN) ÷ 대물렌즈 배율
```

이 값은 검산용입니다. 실제 이미지 측정에는 대물마이크로미터로 구한 축척이 우선됩니다.

분석 이미지에서 `시야 원 3점 지정`을 누른 뒤 시야 경계 위의 점 세 개를 선택하면 실측 시야 지름과 면적을 계산합니다.

### 5. 분석 이미지 측정

`분석 이미지 선택`으로 측정할 사진을 불러온 뒤 도구를 선택합니다.

- `길이`: 시작점과 끝점을 클릭
- `원 지름`: 지름의 양 끝을 클릭
- `면적`: 꼭짓점을 차례로 클릭하고 `면적 완료` 선택
- `이동`: 사진을 드래그하여 이동
- 마우스 휠: 확대·축소

면적 측정은 마지막 점을 더블클릭하는 대신 `면적 완료` 버튼을 사용하는 것이 더 안정적입니다.

### 6. 스케일바와 결과 저장

축척이 적용된 상태에서 스케일바 길이와 색상을 선택하고 `스케일바 삽입`을 누릅니다. 이미지에서 원하는 위치를 클릭해 스케일바를 이동할 수 있습니다.

- `PNG 저장`: 원본 이미지 위에 측정선, 꼭짓점, 시야 원, 스케일바와 분석값을 표시하여 저장
- `CSV 저장`: 길이, 면적, 둘레 및 원형도 등의 수치 자료 저장

## 보정 프로필은 어디에 저장되나요?

보정 프로필은 웹 브라우저의 `localStorage`에 저장됩니다.

- 현재 사용 중인 브라우저와 기기에만 보관됩니다.
- 다른 컴퓨터나 다른 브라우저에는 자동으로 전달되지 않습니다.
- 브라우저의 사이트 데이터나 인터넷 사용 기록을 삭제하면 프로필도 사라질 수 있습니다.
- 저장소나 GitHub 서버에는 업로드되지 않습니다.

프로필에는 축척, 광학 정보, 시야 원과 촬영 조건 메모가 저장됩니다. 기준 사진이나 분석 사진 자체는 저장되지 않습니다.

## 정확도를 높이는 방법

- 기준 이미지와 분석 이미지는 반드시 같은 광학·촬영 조건으로 촬영합니다.
- 자동 리사이즈, 메신저 전송 압축, 화면 캡처를 피합니다.
- 대물마이크로미터 눈금은 가능한 한 길게 잡아 보정합니다.
- 서로 떨어진 위치에서 2~3회 보정하여 값이 비슷한지 확인합니다.
- 기준 눈금과 측정 지점을 확대하여 정확한 위치를 클릭합니다.
- 사진이 크롭되었거나 리사이즈되었다면 원본과 동일한 비율인지 확인합니다.
- 시야 원은 경계가 명확한 서로 떨어진 세 점으로 지정합니다.

## 결과 해석 시 주의사항

이 앱의 결과는 디지털 이미지의 픽셀과 사용자가 지정한 위치를 기반으로 계산됩니다. 다음 요인은 오차를 만들 수 있습니다.

- 기준 눈금의 끝점을 부정확하게 클릭한 경우
- 기준 이미지와 분석 이미지의 배율·줌·해상도가 다른 경우
- 이미지가 비균일하게 리사이즈되거나 변형된 경우
- 렌즈 왜곡이 큰 이미지 가장자리
- 흐릿하거나 경계가 불분명한 대상
- 다각형 꼭짓점 수가 부족하거나 경계를 정확히 따르지 않은 경우

교육 실험과 탐구 활동을 위한 반자동 측정 도구이며, 의료 진단·법적 판정·공인 계측을 대신하지 않습니다.

## 개인정보와 이미지 처리

불러온 기준 이미지와 분석 이미지는 브라우저 내부에서만 처리되며 앱의 분석 서버로 전송되지 않습니다. 다만 결과 파일을 사용자가 다른 서비스에 업로드하거나 공유하는 경우에는 해당 서비스의 개인정보 정책이 적용됩니다.
