# 현미경 이미지 길이·면적 분석기

대물마이크로미터와 현미경 시야원을 이용해 이미지의 픽셀을 실제 길이로 보정하고, 길이·원 지름·다각형 면적 등을 측정하는 과학교육용 웹 애플리케이션입니다.

- 웹앱: <https://sciencegom.github.io/microscope-analyzer/>
- 제작: LJB · DGHS (Daejeon Goejeong High School)
- 권장 환경: 최신 Chrome 또는 Microsoft Edge
- 이미지 처리: 별도 분석 서버로 전송하지 않고 사용자의 브라우저 내부에서 처리
- 라이선스: MIT

## 주요 기능

- 처음 사용하는 학생을 위한 단계별 안내 모드
- 모든 설정을 한 화면에서 사용하는 전체 도구 모드
- 다음에 수행할 버튼을 알려주는 맥박형 안내
- 대물마이크로미터를 이용한 `μm/px` 직접 보정
- 기준 이미지와 분석 이미지의 시야원을 이용한 시야원 전달 보정
- 직접 보정·시야원 보정·자동 추천 중 보정 방법 선택
- 최대 3회 반복 보정과 평균값·표준편차 확인
- 길이, 원 지름, 다각형 면적, 둘레와 원형도 측정
- 시야 지름·시야 면적·이미지 포함 비율 계산
- 화면 확대·축소, 드래그 이동, 가운데 마우스 버튼 임시 이동
- 측정선과 분석값이 포함된 PNG 저장
- 측정 결과 CSV 및 PDF 보고서 저장
- 브라우저 보정 프로필 저장 및 다시 불러오기

## 권장 측정 순서

1. 대물마이크로미터가 촬영된 기준 이미지를 선택합니다.
2. 실제 길이를 아는 긴 눈금 구간을 1~3회 측정하고 평균 보정값을 적용합니다.
3. 같은 기준 이미지에서 시야 경계의 점 3개를 선택하여 기준 시야의 실제 지름을 계산합니다.
4. 측정할 분석 이미지를 선택합니다.
5. 분석 이미지에서 전체 시야원이 보이면 경계의 점 3개를 선택합니다.
6. 자동 추천, 시야원 보정 또는 대물마이크로미터-픽셀 직접 보정 중 하나를 확정합니다.
7. 길이·원 지름·면적을 측정하고 결과를 저장합니다.

단계별 안내 모드에서는 현재 수행해야 할 버튼이 천천히 맥박처럼 강조됩니다. 여러 선택지 중 하나를 고르는 단계에서는 가능한 버튼들이 함께 강조됩니다.

## 보정 원리

### 대물마이크로미터-픽셀 직접 보정

```text
직접 축척(μm/px) = 기준 구간의 실제 길이(μm) ÷ 기준 구간의 픽셀 길이(px)
```

기준 이미지와 분석 이미지의 촬영 크기, 해상도, 디지털 줌 및 크롭 조건이 동일할 때 적합합니다.

### 시야원 전달 보정

기준 이미지에서 직접 축척과 시야원 픽셀 지름을 이용해 실제 시야 지름을 구합니다.

```text
기준 시야 실제 지름(μm)
= 직접 축척(μm/px) × 기준 이미지 시야 지름(px)

분석 이미지 축척(μm/px)
= 기준 시야 실제 지름(μm) ÷ 분석 이미지 시야 지름(px)
```

동일한 광학 조건에서 사진이 균일하게 확대·축소된 경우 그 차이를 보완할 수 있습니다. 시야원 보정은 사진 전체의 축척 차이를 보완하지만, 렌즈의 위치별 왜곡까지 제거하지는 않습니다.

### 실제 측정값

```text
실제 길이(μm) = 측정 픽셀 길이(px) × 축척(μm/px)

실제 면적(μm²) = 측정 픽셀 면적(px²) × 축척²
```

## 정확도를 높이는 방법

- 기준 이미지와 분석 이미지는 같은 대물렌즈·접안렌즈·카메라 조건에서 촬영합니다.
- 스마트폰 렌즈를 접안렌즈와 평행하게 놓고 광축 중심을 맞춥니다.
- 짧은 눈금 한 칸보다 여러 눈금에 걸친 긴 구간으로 보정합니다.
- 서로 다른 구간에서 반복 측정하고 편차를 확인합니다.
- 시야원은 경계가 선명하고 서로 멀리 떨어진 점 3개로 지정합니다.
- 정밀 측정 대상은 렌즈 왜곡이 상대적으로 작은 시야 중앙에 배치합니다.
- 메신저 압축, 비균일 리사이즈 및 불필요한 화면 캡처를 피합니다.

## 보정 프로필 저장 위치

보정 프로필은 현재 브라우저의 `localStorage`에 저장됩니다.

- 현재 기기와 브라우저에서만 사용할 수 있습니다.
- 브라우저의 사이트 데이터를 삭제하면 함께 지워질 수 있습니다.
- 사진 원본은 프로필이나 GitHub 저장소에 저장되지 않습니다.
